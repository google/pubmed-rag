# Reporter

Synthesizes scored articles into a structured markdown literature review.

| | |
| :-- | :-- |
| **Reads** | `state["scored_articles"]`, `state["disease"]`, `state["concepts"]` |
| **Writes** | `state["final_report"]` (written by the tool) |
| **output_key** | `reporter_note` (short acknowledgement only) |
| **Tools** | `write_report(case_notes)` |
| **Model** | `MODEL_ID` (default `gemini-3.6-flash`) |
| **Depends on** | `agents.core` only |

## What it does

Takes the top 10 scored articles and renders an 11-section review: executive
summary, findings by concept, methodological landscape, temporal trends,
cross-study patterns, controversies, knowledge gaps, practical applications,
quality assessment, conclusions, bibliography.

Output is prefixed with the scored-results table so a reader can see the
ranking that produced the synthesis before reading the prose.

The tool writes `state["final_report"]` itself. Asking a model to echo a
20k-character report verbatim is unreliable, so callers read the artifact from
state and treat the agent's text as a status line.

## Citation integrity

Identifiers are never generated by the model. They come from BigQuery and are
rendered by `agents.core.links`, which drops any link that would not resolve —
part of the corpus has `pmid = "0"`, meaning a PMC record with no PubMed ID, and
rendering that verbatim produces a 404. Those fall back to the PMCID.

The prompt also instructs the model to cite by PMCID rather than "Article 1",
so every claim in the prose traces to a specific paper.

## Composing with it

Requires `state["scored_articles"]`. To report on a different scorer, write
that key and reuse this agent unchanged:

```python
SequentialAgent(name="custom", sub_agents=[librarian_agent, my_scorer, reporter_agent])
```

## Cost

One Gemini call, but a large one: 10 articles at 5000 characters each plus the
template. Budget around 60 s and roughly 60k input tokens.
